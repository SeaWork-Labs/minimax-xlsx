# Excel 文件处理

创建与分析 Excel 表格，支持公式、图表与格式整理。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/minimax-xlsx#v1.0.4 --skill minimax-xlsx
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill minimax-xlsx
```

## 内容

技能正文在 `skills/minimax-xlsx/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/minimax-xlsx/payload/`，不要反向同步。版本以 git tag 为准。
